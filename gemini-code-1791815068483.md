# EduGenie: Google Gemini Powered Learning Assistant

EduGenie is an AI-powered educational application built with Python FastAPI and Tailwind CSS. Leveraging Google's official `google-genai` SDK, it generates structured study guides, key summaries, practice quiz questions, and flashcards from any input topic or lesson text.
